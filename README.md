# Projet ETL avec MongoDB

## Description

Ce projet a pour objectif de réaliser un pipeline ETL permettant d'extraire des données depuis plusieurs sources :

- Un fichier CSV
- Une base de données SQLite
- Une API Open-Meteo

Les données sont ensuite transformées et chargées dans MongoDB.

## Technologies utilisées

- Python
- Pandas
- SQLite
- MongoDB
- Requests

## Fonctionnalités

- Extraction des données
- Transformation des données
- Chargement dans MongoDB
- Journalisation des exécutions (pipeline_logs)
